# Task 3: Information Architecture and Wireframes

## Project Overview

This project focuses on creating the information architecture, user flow, sitemap, and low-fidelity wireframes for a student support platform.

The objective is to convert user requirements into a clear and simple navigation structure and responsive wireframe design.

## Contents

- User Flow
- Sitemap
- Mobile Wireframes
- Loading State
- Error State
- Success State
- Desktop Wireframe Adaptation

## Main User Journey

1. Open the platform
2. View assigned tasks
3. Read task instructions
4. Find required resources if needed
5. Upload proof of completion
6. Receive submission success or error message

## Wireframe Screens

The wireframes include:

- Home Screen
- Task List
- Task Details
- Resources
- Upload Proof
- Loading State
- Error State
- Success State
